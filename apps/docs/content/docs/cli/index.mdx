The Fumadocs CLI helps you scaffold, build, and manage documentation projects from the command line.

## Coming Soon

The CLI is under active development. It will provide:

- **Project scaffolding** — create new Fumadocs projects with sensible defaults
- **Content generation** — auto-generate pages from templates
- **Build optimization** — analyze and optimize your docs site
- **Migration tools** — move from other documentation frameworks

## Installation

```bash
npm install -g fumadocs-cli
```

## Current Packages

While the CLI is being built, use the core packages directly:

- [Library](/docs/library) — overview and getting started
- [Core](/docs/core) — timeline engine
- [React](/docs/react) — React bindings
- [UI Components](/docs/ui) — drop-in components
