The Timelinx CLI provides command-line tooling for scaffolding, managing, and building timeline projects.

## Coming Soon

The CLI is under active development. It will provide:

- **Project scaffolding**  - create new Timelinx projects with sensible defaults
- **Content generation**  - auto-generate timeline presets and configurations
- **Build optimization**  - analyze and optimize your timeline app bundle
- **Migration tools**  - import timelines from other formats (FCP XML, DaVinci Resolve, Premiere Pro)

## Current Packages

While the CLI is being built, use the core packages directly:

- [Library](/docs/library)  - overview and getting started
- [Core](/docs/core)  - timeline engine
- [React](/docs/react)  - React bindings
- [UI Components](/docs/ui)  - drop-in components
