This guide builds a minimal edit using `@timelinx/core`, then shows where the React and UI packages fit when you are ready to render an editor. The examples use frame values on purpose: Timelinx stores timeline time as branded integer frames, not milliseconds or floating seconds.

## Prerequisites

- Node.js `>= 22`
- A package manager such as npm or pnpm
- TypeScript recommended for branded IDs and `TimelineFrame` safety

## Install

```bash
npm install @timelinx/core
```

For React apps:

```bash
npm install @timelinx/core @timelinx/react @timelinx/ui
```

Use the thinnest layer that solves your problem: `@timelinx/core` for headless data and validation, `@timelinx/react` for subscription-safe React state, and `@timelinx/ui` for ready editor surfaces and panels.

## Build The Initial State

A usable timeline state has two important parts:

- `timeline`: sequence settings, duration, tracks, markers, in/out points, groups, and version.
- `assetRegistry`: a `ReadonlyMap` of media assets that clips are allowed to reference.

```ts
import {
  createAsset,
  createTimeline,
  createTimelineState,
  frameRate,
  toFrame,
} from '@timelinx/core';

const asset = createAsset({
  id: 'asset-interview',
  name: 'Interview.mp4',
  mediaType: 'video',
  filePath: '/media/interview.mp4',
  intrinsicDuration: toFrame(6000),
  nativeFps: frameRate(30),
  sourceTimecodeOffset: toFrame(0),
});

const timeline = createTimeline({
  id: 'tl-1',
  name: 'Interview cut',
  fps: frameRate(30),
  duration: toFrame(10800),
});

let state = createTimelineState({
  timeline,
  assetRegistry: new Map([[asset.id, asset]]),
});
```

The asset registry matters. If you insert a clip that references an unknown asset, `dispatch()` rejects the transaction with `ASSET_MISSING`.

## Commit A Track

State changes are transactions. A transaction has an ID, a label for history/UI, a timestamp, and one or more operation primitives.

```ts
import { createTrack, dispatch } from '@timelinx/core';

const videoTrack = createTrack({
  id: 'v1',
  name: 'Video 1',
  type: 'video',
});

const addTrack = dispatch(state, {
  id: 'tx-add-video-track',
  label: 'Add video track',
  timestamp: Date.now(),
  operations: [{ type: 'ADD_TRACK', track: videoTrack }],
});

if (!addTrack.accepted) {
  throw new Error(`${addTrack.reason}: ${addTrack.message}`);
}

state = addTrack.nextState;
```

## Insert A Clip

Clips are viewports into assets. `timelineStart` and `timelineEnd` describe where the clip sits in the edit. `mediaIn` and `mediaOut` describe which portion of the source asset is played.

```ts
import { createClip } from '@timelinx/core';

const clip = createClip({
  id: 'clip-intro',
  assetId: asset.id,
  trackId: videoTrack.id,
  timelineStart: toFrame(0),
  timelineEnd: toFrame(300),
  mediaIn: toFrame(0),
  mediaOut: toFrame(300),
});

const insertClip = dispatch(state, {
  id: 'tx-insert-intro',
  label: 'Insert intro clip',
  timestamp: Date.now(),
  operations: [{ type: 'INSERT_CLIP', trackId: videoTrack.id, clip }],
});

if (!insertClip.accepted) {
  throw new Error(`${insertClip.reason}: ${insertClip.message}`);
}

state = insertClip.nextState;
```

After this transaction, the track contains one clip and `state.timeline.version` has advanced by one.

## Move The Clip

Moving a clip keeps its duration and media bounds intact. The validator checks track existence, locked state, overlap, negative frames, and timeline bounds before anything is committed.

```ts
const moveClip = dispatch(state, {
  id: 'tx-move-intro',
  label: 'Move intro later',
  timestamp: Date.now(),
  operations: [
    {
      type: 'MOVE_CLIP',
      clipId: clip.id,
      newTimelineStart: toFrame(150),
    },
  ],
});

if (!moveClip.accepted) {
  throw new Error(`${moveClip.reason}: ${moveClip.message}`);
}

state = moveClip.nextState;
```

## Add Undo And Redo

The pure history helpers keep snapshots outside the dispatcher. Push only accepted states.

```ts
import {
  canUndo,
  createHistory,
  getCurrentState,
  pushHistory,
  undo,
} from '@timelinx/core';

let history = createHistory(state);

if (moveClip.accepted) {
  history = pushHistory(history, moveClip.nextState);
}

if (canUndo(history)) {
  history = undo(history);
  state = getCurrentState(history);
}
```

For a React editor, the `@timelinx/react` engine wraps this pattern with a `HistoryStack`, snapshots, subscriptions, tools, snapping, playback, keyboard routing, and dispatch.

## Render With React And UI

```tsx
import { TimelineEngine } from '@timelinx/react';
import { TimelineEditor, TimelineProvider } from '@timelinx/ui';

const engine = new TimelineEngine({ initialState: state });

export function App() {
  return (
    <TimelineProvider engine={engine}>
      <TimelineEditor />
    </TimelineProvider>
  );
}
```

Import the UI styles once in your application entrypoint:

```css
@import '@timelinx/ui/styles/tokens';
@import '@timelinx/ui/styles/structure';
@import '@timelinx/ui/styles/presets/dark-pro';
```
