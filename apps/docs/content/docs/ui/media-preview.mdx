The `MediaPreview` displays a preview of the currently selected or hovered media asset. It renders video, audio waveforms, or image thumbnails from the asset registry.

## Usage

```tsx
import { MediaPreview, TimelineProvider, MediaAssetsProvider } from '@timelinx/ui';

function App() {
  return (
    <TimelineProvider engine={engine}>
      <MediaAssetsProvider>
        <MediaPreview />
      </MediaAssetsProvider>
    </TimelineProvider>
  );
}
```

## Context Requirement

`MediaPreview` must be inside both a `TimelineProvider` and a `MediaAssetsProvider`. The timeline provider supplies asset metadata; the media assets provider supplies the file and blob URL registry for rendering previews.
