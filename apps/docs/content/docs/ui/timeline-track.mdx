`TimelineTrack` renders a track header with the track icon, label, and controls for muting/hiding and locking the track.

## Usage

```tsx
import { TimelineTrack, TimelineProvider } from '@timelinx/ui';

function App() {
  return (
    <TimelineProvider engine={engine}>
      <TimelineTrack
        trackId="v1"
        shortId="V1"
        height={48}
        clipCount={3}
        onDelete={(trackId) => console.log('delete', trackId)}
        onAddClip={(trackId) => console.log('add clip', trackId)}
      />
    </TimelineProvider>
  );
}
```

## Context Requirement

`TimelineTrack` must be inside a `TimelineProvider`. It reads the track data and engine reference from context to render mute/lock controls and dispatch toggle actions.
