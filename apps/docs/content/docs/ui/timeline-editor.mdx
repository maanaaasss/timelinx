## Usage

```tsx
import { TimelineEditor } from '@timelinx/ui';
import { TimelineEngine } from '@timelinx/react';
import { createTimeline, createTimelineState, toFrame, frameRate } from '@timelinx/core';

const engine = new TimelineEngine({
  initialState: createTimelineState({
    timeline: createTimeline({
      id: 'tl-1',
      name: 'My Edit',
      fps: frameRate(30),
      duration: toFrame(9000),
    }),
  }),
});

function App() {
  return <TimelineEditor engine={engine} />;
}
```

## Self-Wrapping Provider

`TimelineEditor` automatically wraps itself in `TimelineProvider` and `MediaAssetsProvider` if no existing provider context is detected. This means you can use it standalone without manually setting up providers.
