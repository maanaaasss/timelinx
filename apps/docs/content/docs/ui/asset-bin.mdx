The `AssetBin` displays imported media assets and supports drag-and-drop onto the timeline. It shows thumbnails, file names, and media type icons for each registered asset.

## Usage

```tsx
import { AssetBin, TimelineProvider, MediaAssetsProvider } from '@timelinx/ui';

function App() {
  return (
    <TimelineProvider engine={engine}>
      <MediaAssetsProvider>
        <AssetBin />
      </MediaAssetsProvider>
    </TimelineProvider>
  );
}
```

## Context Requirement

`AssetBin` must be inside both a `TimelineProvider` and a `MediaAssetsProvider`. The timeline provider supplies track and clip state; the media assets provider supplies the file and thumbnail registry for imported assets.
