## Getting Started with Timelinx

Timelinx <span className="text-fd-muted-foreground text-sm">(time-linx)</span> is a **browser-native timeline editor engine**, designed to be predictable, testable, and composable. It consists of multiple layers:

<Cards>
  <Card title="@timelinx/core" href="/docs/core">
    The headless engine. Pure-function dispatch model with invariant validation, transactions, and undo/redo.
  </Card>
  <Card title="@timelinx/react" href="/docs/react">
    React bindings. Hooks, providers, and tool routing via `useSyncExternalStore`.
  </Card>
  <Card title="@timelinx/ui" href="/docs/ui">
    Drop-in components. Tracks, clips, panels, and a full timeline editor.
  </Card>
  <Card title="Fumadocs CLI" href="/docs/cli">
    CLI tools for docs and automation. Scaffold projects and generate content.
  </Card>
</Cards>

<Callout title="Want to learn more?">
  Read our in-depth [What is Timelinx?](/docs/library) introduction.
</Callout>

## Terminology

**Timeline:** A sequence of tracks containing clips, aligned to a timecode basis (frames or timecode).

**Dispatch:** A pure function `(state, command) → result` that validates and applies operations to timeline state.

**Invariant:** A rule that timeline state must satisfy. The dispatch engine checks 24 invariant types before applying any operation.

**Transaction:** A batch of operations applied atomically. If any operation fails validation, the entire transaction is rejected.

Some basic knowledge of React.js would be useful for further customizations.

## Create Your First Timeline

Create a file to set up your timeline:

```ts title="lib/timeline.ts"
import {
  createTimeline,
  createTimelineState,
  createTrack,
  createClip,
  dispatch,
  toFrame,
  frameRate,
} from '@timelinx/core';

// Create a 10-second timeline at 30fps
const timeline = createTimeline({
  id: 'tl-1',
  name: 'My Edit',
  fps: frameRate(30),
  duration: toFrame(3000),
});

const state = createTimelineState({ timeline });

// Add a video track
const track = createTrack({ id: 'v1', name: 'V1', type: 'video', clips: [] });

const result = dispatch(state, {
  id: 'setup',
  label: 'Add track and clip',
  timestamp: Date.now(),
  operations: [
    { type: 'ADD_TRACK', track },
    { type: 'INSERT_CLIP', trackId: track.id, clip: createClip({
      id: 'clip-1',
      assetId: 'my-video',
      trackId: 'v1',
      timelineStart: toFrame(0),
      timelineEnd: toFrame(300),
      mediaIn: toFrame(0),
      mediaOut: toFrame(300),
    })},
  ],
});

if (!result.accepted) {
  throw new Error(`${result.reason}: ${result.message}`);
}

export const initialState = result.nextState;
```

## Render the Editor

Create a React component that renders the timeline editor:

```tsx title="app/editor/page.tsx"
'use client';

import { TimelineEditor } from '@timelinx/ui';
import { initialState } from '@/lib/timeline';

export default function Editor() {
  return <TimelineEditor initialState={initialState} />;
}
```

## FAQ

<Accordions>
  <Accordion id="minimal-install" title="Can I use only @timelinx/core?">
    Yes. `@timelinx/core` is headless — no React, no DOM. Use it with any UI framework or vanilla JS.

    ```bash
    npm install @timelinx/core
    ```
  </Accordion>
  <Accordion id="typescript" title="Does Timelinx support TypeScript?">
    Yes. All packages are written in TypeScript with full type definitions. Operations, state, and components are fully typed.
  </Accordion>
  <Accordion id="state-persistence" title="How do I persist timeline state?">
    State is serializable JSON. Persist to localStorage, IndexedDB, or send to a server:

    ```ts
    // Save
    localStorage.setItem('timeline', JSON.stringify(state));

    // Restore
    const saved = JSON.parse(localStorage.getItem('timeline'));
    ```
  </Accordion>
  <Accordion id="custom-components" title="Can I build custom UI components?">
    Yes. Use `@timelinx/react` hooks (`useTimeline`, `useDispatch`) to build custom components that integrate with the engine.
  </Accordion>
  <Accordion id="state-update" title="How do I update the timeline after initial render?">
    Use `useDispatch` hook to dispatch commands from your components:

    ```tsx
    import { useDispatch } from '@timelinx/react';

    function AddTrackButton() {
      const dispatch = useDispatch();
      return (
        <button onClick={() => dispatch({ type: 'ADD_TRACK', track })}>
          Add Track
        </button>
      );
    }
    ```
  </Accordion>
</Accordions>
