## Introduction

Get up and running with Timelinx in minutes. This guide walks you through installing the packages, creating a timeline, and rendering your first editor.

## Prerequisites

- Node.js >= 22
- A React project (Next.js, Vite, or any React setup)

## Create a Timeline

```ts
import {
  createTimeline,
  createTimelineState,
  createTrack,
  createClip,
  dispatch,
  toFrame,
  frameRate,
} from '@timelinx/core';

// Create a 10-second timeline at 30fps
const timeline = createTimeline({
  id: 'tl-1',
  name: 'My Edit',
  fps: frameRate(30),
  duration: toFrame(3000),
});

const state = createTimelineState({ timeline });
```

## Add a Track and Clip

```ts
const track = createTrack({ id: 'v1', name: 'V1', type: 'video', clips: [] });

const result = dispatch(state, {
  id: 'setup',
  label: 'Add track and clip',
  timestamp: Date.now(),
  operations: [
    { type: 'ADD_TRACK', track },
    { type: 'INSERT_CLIP', trackId: track.id, clip: createClip({
      id: 'clip-1',
      assetId: 'my-video',
      trackId: 'v1',
      timelineStart: toFrame(0),
      timelineEnd: toFrame(300),
      mediaIn: toFrame(0),
      mediaOut: toFrame(300),
    })},
  ],
});

if (!result.accepted) {
  throw new Error(`${result.reason}: ${result.message}`);
}

const ready = result.nextState;
```

## Render the Editor

```tsx
'use client';

import { TimelineEditor } from '@timelinx/ui';

export default function Editor() {
  return <TimelineEditor initialState={ready} />;
}
```

That's it. You have a working timeline editor with tracks, clips, zoom, drag, undo/redo, and keyboard shortcuts.

## FAQ

<Accordions>
  <Accordion id="minimal-install" title="Can I use only @timelinx/core?">
    Yes. `@timelinx/core` is headless — no React, no DOM. Use it with any UI framework or vanilla JS.

    ```bash
    npm install @timelinx/core
    ```
  </Accordion>
  <Accordion id="typescript" title="Does Timelinx support TypeScript?">
    Yes. All packages are written in TypeScript with full type definitions. Operations, state, and components are fully typed.
  </Accordion>
  <Accordion id="state-persistence" title="How do I persist timeline state?">
    State is serializable JSON. Persist to localStorage, IndexedDB, or send to a server:

    ```ts
    // Save
    localStorage.setItem('timeline', JSON.stringify(state));

    // Restore
    const saved = JSON.parse(localStorage.getItem('timeline'));
    ```
  </Accordion>
  <Accordion id="custom-components" title="Can I build custom UI components?">
    Yes. Use `@timelinx/react` hooks (`useTimeline`, `useDispatch`) to build custom components that integrate with the engine.
  </Accordion>
</Accordions>
