## Prerequisites

- Node.js ≥ 22
- React ≥ 18 (Next.js, Vite, or any setup)
- TypeScript ≥ 5.0

## Install

```bash
pnpm add @timelinx/core @timelinx/react @timelinx/ui
```

Then add the CSS to your global stylesheet. Both imports are required:

```css
/* globals.css */
@import '@timelinx/ui/styles/presets/dark-pro';
@import '@timelinx/ui/styles/structure';
```

See [Installation](/docs/library/installation) for Next.js, Vite, and framework-specific notes.

## Create an Initial State

State is a plain object. Build it once with factory functions:

```ts title="lib/timeline.ts"
import {
  createTimeline,
  createTimelineState,
  createTrack,
  createClip,
  createAsset,
  dispatch,
  toFrame,
  toTrackId,
  toAssetId,
  frameRate,
} from '@timelinx/core';

// 10-minute timeline at 30fps
const timeline = createTimeline({
  id: 'tl-1',
  name: 'My Edit',
  fps: frameRate(30),
  duration: toFrame(18000),
});

const emptyState = createTimelineState({ timeline });

// A video asset must be registered before any clip can reference it
const videoAsset = createAsset({
  id: 'asset-1',
  name: 'interview.mp4',
  mediaType: 'video',
  filePath: '/media/interview.mp4',
  intrinsicDuration: toFrame(9000), // 5 minutes
  nativeFps: frameRate(30),
  sourceTimecodeOffset: toFrame(0),
});

const videoTrack = createTrack({ id: 'v1', name: 'V1', type: 'video' });

const result = dispatch(emptyState, {
  id: 'tx-setup',
  label: 'Setup timeline',
  timestamp: Date.now(),
  operations: [
    // 1. Register the asset first — clips must reference an existing asset
    { type: 'REGISTER_ASSET', asset: videoAsset },
    // 2. Add the track
    { type: 'ADD_TRACK', track: videoTrack },
    // 3. Place a clip (references the asset registered in step 1)
    {
      type: 'INSERT_CLIP',
      trackId: toTrackId('v1'),
      clip: createClip({
        id: 'clip-1',
        assetId: toAssetId('asset-1'),
        trackId: toTrackId('v1'),
        timelineStart: toFrame(0),
        timelineEnd: toFrame(300),  // 10 seconds at 30fps
        mediaIn: toFrame(0),
        mediaOut: toFrame(300),
      }),
    },
  ],
});

if (!result.accepted) {
  throw new Error(`Setup failed: ${result.reason} — ${result.message}`);
}

export const initialState = result.nextState;
```

## Render the Editor

Create a `TimelineEngine` from your initial state and pass it to `TimelineEditor`:

```tsx title="app/editor/page.tsx"
'use client'; // Next.js only

import { TimelineEngine } from '@timelinx/react';
import { TimelineEditor } from '@timelinx/ui';
import { initialState } from '@/lib/timeline';

// Create the engine once, outside the component
const engine = new TimelineEngine({ initialState });

export default function EditorPage() {
  return (
    <div style={{ height: '100vh' }}>
      <TimelineEditor engine={engine} />
    </div>
  );
}
```

`TimelineEditor` gives you: toolbar, ruler, track list, clip drag and resize, zoom controls, transport, sidebar, and keyboard shortcuts — all wired to the engine.

## Run It

```bash
pnpm dev
```

Open the page. You should see a dark timeline editor with one video track and a clip at the start. Try dragging the clip, pressing ⌘Z to undo, and using the zoom controls.

## FAQ

<Accordions>
  <Accordion id="headless" title="Can I use only @timelinx/core without React?">
    Yes. `@timelinx/core` is headless — no React, no DOM. Use it for server-side processing, tests, or with any other UI framework.
  </Accordion>
  <Accordion id="typescript" title="Is TypeScript required?">
    Not required, but strongly recommended. All packages are written in TypeScript with full type definitions. Operations, state, and hook return types are fully typed.
  </Accordion>
  <Accordion id="register-asset" title="Why do I need REGISTER_ASSET before INSERT_CLIP?">
    Clips reference assets by ID. The dispatcher validates that `assetId` exists in `assetRegistry` before accepting `INSERT_CLIP`. This prevents orphan clips that reference non-existent media — a common source of broken project files.
  </Accordion>
  <Accordion id="persist" title="How do I save and restore the timeline?">
    State is serializable JSON. Pass it through `serializeProject()` for versioned storage:

    ```ts
    import { serializeProject, deserializeProject } from '@timelinx/core';

    // Save
    const json = JSON.stringify(serializeProject(state));
    localStorage.setItem('project', json);

    // Restore
    const saved = JSON.parse(localStorage.getItem('project')!);
    const state = deserializeProject(saved); // handles migrations
    ```
  </Accordion>
  <Accordion id="editor-height" title="TimelineEditor has no height — how do I fix it?">
    `TimelineEditor` fills its container. Give the container an explicit height:

    ```tsx
    <div style={{ height: '60vh' }}>
      <TimelineEditor engine={engine} />
    </div>
    ```
  </Accordion>
</Accordions>
