## Core Internal Architecture

`@timelinx/core` is the foundation  - a deterministic, frame-based editing kernel with zero runtime dependencies.

```mermaid
graph TD
    subgraph "@timelinx/core"
        direction TB

        subgraph "State Model"
            STATE["TimelineState"]
            TL["Timeline"]
            TRACKS["Tracks"]
            CLIPS["Clips"]
            ASSETS["Assets"]
            MARKERS["Markers"]
            STATE --> TL
            STATE --> TRACKS
            STATE --> CLIPS
            STATE --> ASSETS
            STATE --> MARKERS
        end

        subgraph "Dispatch Engine"
            DISPATCH["dispatch()"]
            VALIDATE["Invariant Checker"]

            DISPATCH --> VALIDATE
            VALIDATE --> APPLY

    style STATE fill:#818cf8,stroke:#6366f1,color:#fff
    style DISPATCH fill:#fbbf24,stroke:#f59e0b,color:#000
    style HISTORY fill:#a78bfa,stroke:#8b5cf6,color:#fff
    style REGISTRY fill:#f472b6,stroke:#ec4899,color:#fff
```

**Key design decisions:**
- **Pure functions**  - `dispatch(state, command)` returns a new state or a rejection. No mutations, no side effects.
- **Branded IDs**  - `ClipId`, `TrackId`, `AssetId` are branded string types that prevent accidental misuse.
- **Frame-based time**  - All positions are integer frames, eliminating floating-point drift.
- **24 invariant types**  - Every mutation is validated before it's applied.

## End-to-End Data Flow

This is how a user interaction flows through the entire stack:

```mermaid
sequenceDiagram
    participant User
    participant UI as @timelinx/ui
    participant React as @timelinx/react
    participant Core as @timelinx/core
    participant Media as @timelinx/media-web

    User->>UI: Click / Drag / Keyboard
    UI->>React: ToolRouter maps event
    React->>Core: dispatch(state, command)
    Core->>Core: Validate invariants
    Core->>Core: Apply operation
    Core->>Core: Push to history
    Core-->>React: New state (or rejection)
    React-->>UI: useSyncExternalStore triggers re-render
    UI-->>User: Updated visual

    Note over Media,Core: Media pipeline runs in parallel
    UI->>Media: Request frame decode
    Media->>Core: Read clip/asset metadata
    Media-->>UI: Decoded frame / waveform
```

`@timelinx/core` supports multiple interchange formats for professional workflows:

```mermaid

    STATE -->|"serialize"| JSON["JSON"]
    STATE -->|"export"| OTIO["OpenTimelineIO"]
    STATE -->|"export"| FCPXML["FCPXML"]
    STATE -->|"export"| EDL["CMX3600 EDL"]
    STATE -->|"export"| AAF["AAF"]

    style STATE fill:#818cf8,stroke:#6366f1,color:#fff
    style JSON fill:#fbbf24,stroke:#f59e0b,color:#000
```

All state is plain objects  - no class instances, no circular references. Serialize to JSON, persist anywhere, sync across tabs, or send to a server.
