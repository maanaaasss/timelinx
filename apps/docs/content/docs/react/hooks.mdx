## Setup

Wrap your app with `TimelineProvider` and use the hooks inside:

```tsx
import { TimelineProvider, useEngine } from '@timelinx/ui';
import { TimelineEngine } from '@timelinx/react';
import { createTimeline, createTimelineState, toFrame, frameRate } from '@timelinx/core';

const engine = new TimelineEngine({
  initialState: createTimelineState({
    timeline: createTimeline({
      id: 'tl-1',
      name: 'My Edit',
      fps: frameRate(30),
      duration: toFrame(9000),
    }),
  }),
});

function App() {
  return (
    <TimelineProvider engine={engine}>
      <TimelineView />
    </TimelineProvider>
  );
}
```

## Reading State

### `useEngine()`

Returns the engine instance. Use this to dispatch operations:

```tsx
const engine = useEngine();
engine.dispatch({ /* transaction */ });
```

### `useEngine()`

Returns the engine instance from the `@timelinx/ui` `TimelineProvider` context. Use this to dispatch operations or pass to engine-first hooks:

```tsx
const engine = useEngine();
engine.dispatch({ /* transaction */ });
```

## Granular Re-renders

Hooks use `useSyncExternalStore` to subscribe to specific slices of state. A component that reads `state.timeline.duration` will only re-render when the duration changes — not when clips or tracks change.

## Hook Reference

| Hook | Returns | Re-renders when |
|------|---------|-----------------|
| `useEngine()` | `TimelineEngine` | Never (stable reference) |
| `useClip(clipId)` | `Clip \| null` | That clip's data changes |
| `useSelectedClipIds(engine)` | `ReadonlySet<string>` | Selection changes |
| `usePlayheadFrame(engine)` | `TimelineFrame` | Playhead moves |
| `useIsPlaying(engine)` | `boolean` | Play/pause state changes |
| `useTimelineWithEngine(engine)` | `Timeline` | Timeline metadata changes |
