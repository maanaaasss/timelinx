## Basic Usage

```tsx
import { TimelineProvider } from '@timelinx/ui';
import { TimelineEngine } from '@timelinx/react';
import { createTimeline, createTimelineState, toFrame, frameRate } from '@timelinx/core';

const engine = new TimelineEngine({
  initialState: createTimelineState({
    timeline: createTimeline({
      id: 'tl-1',
      name: 'My Edit',
      fps: frameRate(30),
      duration: toFrame(9000),
    }),
  }),
});

function App() {
  return (
    <TimelineProvider engine={engine}>
      <YourComponents />
    </TimelineProvider>
  );
}
```

## What the Provider Does

- Creates a React context for the timeline engine
- Enables all `use*` hooks to access the engine
- Manages subscription lifecycle (subscribe/unsubscribe on mount/unmount)
- Ensures components re-render only when their subscribed state changes

## With @timelinx/ui

When using `@timelinx/ui` components, the provider is typically set up at the top level:

```tsx
import { TimelineProvider, TimelineEditor } from '@timelinx/ui';

function App() {
  return (
    <TimelineProvider engine={engine}>
      <TimelineEditor />
    </TimelineProvider>
  );
}
```

The `TimelineEditor` component and all other `@timelinx/ui` components consume the provider's context internally.

## MediaAssetsProvider

For media import functionality, wrap with `MediaAssetsProvider`:

```tsx
import { MediaAssetsProvider, TimelineProvider } from '@timelinx/ui';

function App() {
  return (
    <MediaAssetsProvider>
      <TimelineProvider engine={engine}>
        <TimelineEditor />
      </TimelineProvider>
    </MediaAssetsProvider>
  );
}
```
